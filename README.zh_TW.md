# StartAllBack 無障礙增強

StartAllBack Accessibility Enhancements

[English](README.md)

作者：圓臉（roundface）

協助 NVDA 朗讀 StartAllBack 設定中的勾選狀態、顯示方式、開始按鈕圖案，以及 14 個下拉式方塊的功能名稱。

## 安裝

從 [Releases](https://github.com/maydayrag/startallback-nvda/releases) 下載 `StartAllBack-1.0.3.nvda-addon`，以 NVDA 安裝並重新啟動 NVDA。

## 操作方式

進入 StartAllBack 後，依一般方式操作即可，NVDA 會自動朗讀目前選取的項目與狀態。

## 鍵盤操作

- Tab／Shift+Tab：移到下一個／上一個控制項。
- 設定清單：上下方向鍵選擇項目，空白鍵切換勾選，左右方向鍵切換選項。
- 同時有勾選和細項的設定：先按空白鍵勾選，再用左右方向鍵修改細項。
- 下拉式方塊：Alt+下方向鍵展開，上下方向鍵選擇，Enter 確認。

上述按鍵不需要搭配 NVDA 鍵。修改設定後，NVDA 會自動朗讀新的狀態。

詳細說明見 [繁體中文操作說明](addon/doc/zh_TW/readme.html)。使用者版不含診斷快捷鍵及資料匯出功能。
