StartAllBack 無障礙增強 1.0.3

作者：圓臉（roundface）

協助 NVDA 朗讀 StartAllBack 設定中的勾選狀態、顯示方式、開始按鈕圖案，以及下拉式方塊的功能名稱。

操作方式

進入 StartAllBack 後，依一般方式操作即可，NVDA 會自動朗讀目前選取的項目與狀態。

鍵盤操作

  • Tab／Shift+Tab：移到下一個／上一個控制項。
  • 設定清單內，上下方向鍵：選擇項目；空白鍵：切換勾選／未勾選；左右方向鍵：切換選項，例如「不顯示」、「顯示為連結」、「顯示為功能表」。
  • 同時有核取方塊和細項的設定：先按空白鍵勾選，再用左右方向鍵修改細項。
  • 下拉式方塊：Alt+下方向鍵展開，上下方向鍵選擇，Enter 確認。

上述按鍵不需要搭配 NVDA 鍵。修改設定後，NVDA 會自動朗讀新的狀態。
