StartAllBack Accessibility Enhancements 1.0.4

Author: roundface

Helps NVDA announce checkbox states, display options, Start button images, and combo box labels in StartAllBack settings.

Usage

If an earlier version with the identifier startAllBackDiagnostics is installed, remove it in NVDA's Add-on Store before installing this version. The new identifier is startallback.

Open StartAllBack and use it as usual. NVDA will automatically announce the currently selected item and its state.

Keyboard commands

  • Tab / Shift+Tab: Move to the next / previous control.
  • In the settings list, Up/Down Arrow selects an item; Space toggles its checkbox; Left/Right Arrow changes its option, such as Don't display, Link, or Menu.
  • For settings with both a checkbox and additional options, press Space to enable the setting, then use Left/Right Arrow to change its option.
  • Combo boxes: Press Alt+Down Arrow to expand, Up/Down Arrow to select, and Enter to confirm.

These commands do not require the NVDA key. After you change a setting, NVDA automatically announces its new state.
